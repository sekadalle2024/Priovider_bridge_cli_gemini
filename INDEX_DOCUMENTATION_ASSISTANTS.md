## 🎯 Commandes essentielles

### Démarrage
```bash
npm run assistants              # Démarrer le serveur
```

### Tests
```bash
node scripts/test-gemini-cli-installation.js  # Tester Gemini CLI
node scripts/test-assistant-complete.js       # Test complet
npm run test:gemini-3-flash                   # Test modèle
```

### Gemini CLI
```bash
gemini                          # Mode interactif
gemini -p "prompt"             # Requête simple
gemini -m gemini-2.5-flash -p "prompt"  # Avec modèle
gemini --version               # Version
gemini auth login              # Authentification
```

### Vérification
```bash
curl http://localhost:25810/health              # Health check
curl http://localhost:25810/api/v1/models       # Liste des modèles
```
